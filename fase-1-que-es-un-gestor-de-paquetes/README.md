# FASE 1 — Qué es un gestor de paquetes

**Idea central:** instalar software no es hacer clic en Siguiente. Es una tarea de administración que se puede escribir, repetir y auditar.

Marko lleva toda la vida instalando programas como todo el mundo: busca el nombre, entra en la primera web que sale, baja un `.exe` y acepta. En esta fase descubre que **su Windows ya traía otra forma de hacerlo puesta de fábrica**, y por qué la que usaba es la peor de las dos.

Nada de automatizar ni de comparar herramientas todavía: primero hay que entender qué es esto y de dónde sale el software.
